# Sistema-de-Petshop-Majulle

Sistema de gerenciamento de animais de estimação desenvolvido em **C#**, com o objetivo de praticar conceitos fundamentais de **Programação Orientada a Objetos (POO)**.

## Objetivo

Desenvolver um sistema simples para cadastrar e listar animais de um PetShop, exibindo suas informações, seus sons e calculando a média de idade dos pets cadastrados.

## Conceitos utilizados

- Classes e objetos
- Encapsulamento
- Construtores
- Herança
- Polimorfismo
- Sobrescrita de métodos (`override`)
- Listas (`List`)
- Métodos
- Estruturas condicionais (`if`, `switch`)
- Estruturas de repetição (`do while`, `foreach`)
- Validação de dados (`TryParse`)
- LINQ (`Average`)

## Animais

O sistema possui:

- `Animal` — classe base
- `Cachorro` — classe derivada
- `Gato` — classe derivada
- `Hamster` — classe derivada
- `Outro` — classe derivada para outras espécies
- `PetShop` — gerenciamento dos animais

## Funcionalidades

- Cadastrar animais
- Listar animais cadastrados
- Exibir informações dos animais
- Emitir sons específicos para cada animal
- Informar características específicas de cada pet
- Calcular a média de idade dos pets
- Validar os dados informados pelo usuário
- Menu interativo pelo console

- C#
